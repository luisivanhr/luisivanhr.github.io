Hawkes Tools example notebook¶

Simulation, estimation, and diagnostic examples from the Hawkes Tools repository, using its gallery notebook at commit 004a122. The experiment numbering follows the source gallery.

This website edition preserves the experiment code and parameters and applies a common style to the figures. It can run with an installed package or from a repository checkout. Examples that require datasets use the package's dataset loader. Some experiments take longer to run.

Setup¶

Use Python 3.11 or later. The installation command requires Git. Install the pinned package and notebook dependencies in your environment:

python -m pip install "hawkes-tools @ git+https://github.com/luisivanhr/hawkes-tools.git@004a1220fdf5be9c11bd55ac8bb534f0d433faf7" jupyter matplotlib-inline

Run the cells in order. To use a repository checkout, install its dependencies before running the notebook.

def fast_sparse_random_csr(n_rows, n_cols, density, seed):
    nnz = int(round(n_rows * n_cols * density))
    rng = np.random.default_rng(seed)
    flat = rng.choice(n_rows * n_cols, size=nnz, replace=False)
    rows = (flat // n_cols).astype(np.int32, copy=False)
    cols = (flat % n_cols).astype(np.int32, copy=False)
    data = rng.random(nnz)
    return scipy_sparse.csr_matrix((data, (rows, cols)), shape=(n_rows, n_cols))

def roc_points(y, scores):
    y = np.asarray(y, dtype=bool)
    order = np.argsort(-scores)
    y_sorted = y[order]
    positives = max(int(y.sum()), 1)
    negatives = max(int((~y).sum()), 1)
    tpr = np.r_[0.0, np.cumsum(y_sorted) / positives]
    fpr = np.r_[0.0, np.cumsum(~y_sorted) / negatives]
    return fpr, tpr


def auc_rank(y, scores):
    y = np.asarray(y, dtype=bool)
    ranks = rankdata(scores)
    n_pos = float(y.sum())
    n_neg = float((~y).sum())
    return float((ranks[y].sum() - n_pos * (n_pos + 1.0) / 2.0) / (n_pos * n_neg))
